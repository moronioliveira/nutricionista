# 🥗 Landing Page - Nutricionista

Uma landing page moderna, responsiva e otimizada para a apresentação de serviços de consultoria nutricional, agendamento de consultas e divulgação de especialidades.

---

## 📌 Sobre o Projeto

Este projeto consiste na interface web para um nutricionista. O objetivo principal é fornecer uma presença online profissional, destacando:
* Apresentação do profissional e metodologia de trabalho.
* Planos e serviços oferecidos (emagrecimento, reeducação alimentar, nutrição esportiva, etc.).
* Depoimentos e resultados de pacientes.
* Links de contato direto e formulário para agendamento.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido de forma nativa e leve, sem dependência de bibliotecas ou frameworks externos:

* **HTML5**: Estruturação semântica da página.
* **CSS3**: Estilização, layout flexível (Flexbox/Grid), animações e responsividade (Media Queries).
